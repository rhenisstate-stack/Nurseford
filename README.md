# PubNurse

**PubNurse** is a premier online platform for nursing exam preparation: RN Nursing, LPN Nursing, and RN/LPN Exit Exam Q-Banks.

## Platform Features

- **RN & LPN Question Banks**: Board-standard clinical exam drills with comprehensive clinical rationales.
- **Exit Exam Preparation**: Dedicated tracks for HESI Exam RN/PN, ATI Exam RN/PN, NCLEX-RN, and NCLEX-PN.
- **Dynamic Real-Time Diagnostics**: Performance tracking, pass likelihood scoring, and targeted subject review.

## Tech Stack

- **Framework**: Next.js (App Router)
- **Styling**: Tailwind CSS & Lucide Icons
- **Animation**: Framer Motion
- **Runtime**: Node.js

## Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the application.
